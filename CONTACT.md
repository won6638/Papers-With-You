# Contact / 연락처

Use the Issues tab of this repository for bugs, questions and commercial-permission requests once the private remote exists. During private development only invited collaborators can access it. No public email has been supplied or inferred. A public confidential contact channel must be selected before public release.

비공개 원격 저장소가 생성되면 저장소의 Issues 탭을 오류·질문·상업적 이용 허락 요청 창구로 사용합니다. 비공개 개발 중에는 초대한 협업자만 접근할 수 있습니다. 공개 이메일은 제공받거나 추측하지 않았습니다. public 전환 전 비공개로 연락할 수 있는 공개 연락 수단을 정해야 합니다.

Commercial permission is not automatically granted by opening an issue. It must be explicitly granted by the relevant rights holder(s). Third-party data, models and dependencies retain their own terms.

이슈를 등록했다고 상업적 이용이 자동 허용되는 것은 아닙니다. 해당 권리자의 명시적인 허락이 필요합니다. 외부 데이터·모델·의존성에는 각각의 조건이 적용됩니다.
